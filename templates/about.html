About Our System

Multi-Module Hybrid Deep Learning System

Our advanced image forgery detection system combines the power of deep learning with traditional machine learning algorithms to provide accurate and reliable detection of manipulated images.

Technology Stack

MobileNet CNN

Lightweight deep learning architecture optimized for mobile and embedded vision applications. Provides fast and efficient feature extraction.

  • Pre-trained on ImageNet
  • Transfer learning applied
  • Fast inference time

Support Vector Machine

Powerful classification algorithm using RBF kernel for complex decision boundaries in high-dimensional feature space.

  • RBF kernel
  • Probability estimates
  • Robust to overfitting

Logistic Regression

Linear model for binary classification with probabilistic interpretation of predictions.

  • Fast training
  • Interpretable results
  • Probability output

Decision Tree

Tree-based model that makes decisions based on feature values through a series of if-then-else rules.

  • Easy to interpret
  • Handles non-linear data
  • No feature scaling needed

K-Nearest Neighbors

Instance-based learning algorithm that classifies based on similarity to training samples.

  • Simple and effective
  • No training phase
  • Adapts to new data

Random Forest

Ensemble method combining multiple decision trees for improved accuracy and reduced overfitting.

  • 100 decision trees
  • Feature importance
  • Robust predictions
